# 🌐 Personal Portfolio Website

Welcome to my **Personal Portfolio Website**! This project is a simple and responsive website created to showcase my **skills, projects, education, and contact information**.

## 🚀 About the Project

This portfolio is designed to give a quick overview of who I am, what I can do, and the projects I have worked on. It is built using basic web technologies and focuses on a clean and user-friendly design.

## 🛠️ Technologies Used

* **HTML5** – For creating the structure of the website
* **CSS3** – For styling and designing the website

## ✨ Features

* 👤 About Me section
* 🎓 Education details
* 💻 Skills section
* 📂 Projects showcase
* 📞 Contact information
* 📱 Responsive and simple design

## 📁 Project Structure

```text
PORTFOLIO/
│
├── index.html
├── style.css
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The portfolio website will be displayed.

## 🎯 Purpose

The main purpose of this project is to practice **HTML and CSS** and create an online portfolio that represents my skills and projects.
